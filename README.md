# Gerador de Questões a partir de Transcrições

Um script Python que processa arquivos VTT (transcrições de vídeo) e gera questões de múltipla escolha usando a API da Azure OpenAI.

## Funcionalidades

- Lê e processa arquivos no formato VTT
- Limpa o conteúdo removendo timestamps e formatações
- Gera questões de múltipla escolha (fáceis, médias e difíceis) usando IA
- Cria um documento Word (.docx) com as questões geradas

- Python 3.8+
- Conta na Azure OpenAI com API key
